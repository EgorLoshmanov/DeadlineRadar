# Подключение Groq

Groq подключается через существующий клиент совместимого Chat Completions API.
Дополнительные библиотеки не нужны. Ключ хранится только в локальном `.env`.

## Настройка

Замените параметры LLM в `.env`, сохранив токен Telegram, путь к БД и часовой пояс:

```ini
LLM_PROVIDER=openai
LLM_API_KEY=ваш_ключ_Groq
LLM_MODEL=qwen/qwen3.8-27b
LLM_API_URL=https://api.groq.com/openai/v1/chat/completions
LLM_TIMEOUT=5
LLM_REASONING_EFFORT=none
LLM_CHAT_TEMPLATE_KWARGS=
LLM_CA_BUNDLE=
```

`openai` обозначает формат API; запросы отправляются по указанному адресу в Groq.
Вставляйте сам ключ без префикса `Bearer`. Не публикуйте `.env` и не включайте его в Git.

Для [Qwen в Groq](https://console.groq.com/docs/model/qwen/qwen3.8-27b)
`reasoning_effort=none` выбирает режим без рассуждений. Это снижает объём генерации,
но не гарантирует ответ за пять секунд. Модель имеет статус Preview; доступность
и ограничения следует проверять для своего аккаунта.

Очистите `LLM_CHAT_TEMPLATE_KWARGS`: прежний параметр `enable_thinking` для API НГУ
в этом варианте заменён на `LLM_REASONING_EFFORT`. Пустой `LLM_CA_BUNDLE` использует
системные доверенные сертификаты. Клиент автоматически добавляет
`User-Agent: DeadlineRadar/1.0`, идентифицируя приложение при запросах.

## Проверка на сервере

В каталоге проекта выполните:

```bash
runuser -u deadlineradar -- .venv/bin/python main.py --check-llm
```

Для локальной проверки используйте `.venv/bin/python main.py --check-llm`.
Команда отправляет тестовую фразу модели, проверяет результат и не обращается
к Telegram или рабочей БД. Успех обозначается строкой `Проверка LLM пройдена`.
Получение списка моделей подтверждает доступ к списку, но не заменяет проверку генерации.

При таймауте, отказе API или некорректном ответе проверка завершается с ошибкой;
обычный бот в этих случаях использует локальный парсер. Бюджет ожидания модели
ограничен пятью секундами. При смене модели очистите `LLM_REASONING_EFFORT`,
если её поддержка этого параметра не подтверждена документацией сервиса.

После изменения `.env` перезапустите работающий бот. Если создана служба systemd:

```bash
systemctl restart deadlineradar
journalctl -u deadlineradar -n 30 --no-pager
```
